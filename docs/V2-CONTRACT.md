# QuoteLens online product contract

Root owns `dist/index.html`, `dist/app.js`, `dist/style.css`, `dist/store.js`, deployment, Git and product guide/case study. Domain agent owns `dist/core.js`, `tests/core.test.cjs` and `docs/CORE.md`; do not touch root files. Browser-first, zero dependencies, no remote data/model calls. Local browser persistence + portable JSON files; public hosting is the app, not users' data. Existing Python local v1 remains available and untouched.

Core module uses UMD (`globalThis.QL` + module.exports) and all functions work in Node. Money two decimal places as decimal strings, BigInt internally, no currency mixing or implicit FX/taxes. Unit counts and pack counts are positive safe integers with bounded limits. Delivery fee is explicitly **per offer line**, not supplier-order shipping.

Workspace JSON: `{schemaVersion:2,id,title,date,currency,revision,request:[],offers:[],selections:{},notes:{},history:[],importErrors:[]}`. New starts empty. Request item `{id,label,quantity,unit,maxLeadDays:null|integer}`. Offer `{id,itemId,supplier,quoteId,packSize,packPrice,minPacks,stockPacks,leadDays,validUntil,currency,deliveryFee,source:{filename,line,raw}}`. Currency USD/EUR/GBP/VND; same per workspace. Offer source raw is original input fields. Valid-until ISO date inclusive; review date user-editable.

Required API:

- `newWorkspace({title,date,currency})` returns full workspace with ID/revision1.
- `parseCsv(text)` returns `{headers,rows:[{line,values,raw}],errors:[string]}`; rows values object byheader, raw original field array, line original physical starting line. Support BOM, CRLF, quoted multiline/escapedquotes; reject duplicate/empty headers, excesslength/rowcount, malformedCSV.
- `importCsv(text,mapping,filename)` returns `{offers,errors:[string],headers}`. mapping canonicalField -> CSVheader. Required itemId,supplier,packSize,packPrice. Other defaults: quoteId empty, minPacks1, stockPacks blank means unknown/unlimited? Choose **null = not supplied**, analyzer must label stock unverified rather than infer availability; leadDays null=unknown; validUntil empty=not supplied; currency field optional default MUST use mapping constant? To avoid ambiguity root passes `mapping._currency=workspace.currency`; deliveryFee0. Manual offers use explicit numeric fields. IDs generated, duplicateofferidentities checked byanalyzer.
- `evaluateOffer(item,offer,workspace)` returns `{offer,eligible,reasons:[],warnings:[],packs,units,overage,goodsCost,deliveryCost,total}`; costs decimal strings; reasons block invalid quantities/money/currency/expiry/stock/lead constraint/item identity. Missing stock/lead/expiry are warnings unless needed for a requested constraint. Min pack purchase respected. Availability is total stock packs; cannot buy excessneeded.
- `analyze(workspace)` returns `{items:[{request,offers:[evaluation],selected:evaluation|null,cheapest:evaluation|null}],total,complete,issues:[],warnings:[]}`; total is selected eligible subtotal, complete only every request valid and chosen eligible and nonemptyrequest. Different pack sizes compared at whole actual purchase cost including rowdeliveryfee. Duplicate supplier+quoteId+itemId with conflictingfields blocked; safeexactduplicates not silently favored.
- `fingerprint(workspace)` deterministic canonical content string or explicit noncryptographic ID; exclude history/importErrors and revision? Must include all decision inputs/title/date/currency/request/offers/selections/notes. Do NOT market as cryptographic integrity. Root uses it to invalidate prior approval even if revision mismatch.
- `createReceipt(workspace,nowISO)` throws unless complete. Returns JSON with kind/schemaVersion/id/workspaceId/title/revision/fingerprint/approvedAt/currency/total/lines (selection+source+reason)/snapshot. Same current fingerprint reuses root receipt; nofake signing/tamperproof claims.
- `exportDecisionCsv(workspace)` returns CSV with selected source references/reasons/costs; escape spreadsheet formulas for textcells.
- `validateWorkspace(input)` returns `{valid,errors:[]}`; untrusted portable import strictly checks schema/types/caps, bounded strings, IDsuniqueness, arrays/maps/historylimits. Reject dangerousproto keys; do not let malicious backups execute HTML.

Root edits by structuredClone, increments revision, then saves; history receipts are immutable copies. A selection change makes old approval historical. Domain functions do not mutate inputs. Supplied missing values are not zero; impossible cases stay blocked. No floating-point money arithmetic. CSV formulas neutralized onexport; raw HTML shown escaped in UI.
