# QuoteLens online product contract

This is the current browser product's domain and portable-data contract. The application uses local browser persistence and portable JSON files, with no remote data/model calls. Public hosting serves the application, not users' quote data. The historical Python/SQLite prototype is separate. See [CORE.md](CORE.md) for field validation and [ARCHITECTURE-V2.md](ARCHITECTURE-V2.md) for the complete browser workflow.

Core module uses UMD (`globalThis.QL` + module.exports) and all functions work in Node. Money two decimal places as decimal strings, BigInt internally, no currency mixing or implicit FX/taxes. Requested quantities, pack sizes and minimum packs are positive bounded safe integers. Stock can be zero or null, with distinct unavailable and unverified meanings. Delivery fee is explicitly **per offer line**, not supplier-order shipping.

Workspace JSON: `{schemaVersion:2,id,title,date,currency,revision,request:[],offers:[],selections:{},notes:{},history:[],importErrors:[]}`. A newly created workspace has no request items or offers; the application's opening overview is a separate surface. Request item `{id,label,quantity,unit,maxLeadDays:null|integer}`. Offer `{id,itemId,supplier,quoteId,packSize,packPrice,minPacks,stockPacks,leadDays,validUntil,currency,deliveryFee,source:{filename,line,raw}}`. Currency USD/EUR/GBP/VND; same per workspace. Offer source raw is original input fields. Valid-until ISO date inclusive; review date user-editable.

Public domain API:

- `newWorkspace({title,date,currency})` returns full workspace with ID/revision1.
- `parseCsv(text)` returns `{headers,rows:[{line,values,raw}],errors:[string]}`; rows values object byheader, raw original field array, line original physical starting line. Support BOM, CRLF, quoted multiline/escapedquotes; reject duplicate/empty headers, excesslength/rowcount, malformedCSV.
- `importCsv(text,mapping,filename)` returns `{offers,errors:[string],headers}`. mapping canonicalField -> CSVheader. Required itemId,supplier,packSize,packPrice. Defaults for unmapped fields: quoteId empty, minPacks1, stockPacks **null = not supplied** (availability remains unverified, not unlimited), leadDays null=unknown, validUntil empty=not supplied, deliveryFee0. Unmapped currency requires explicit `mapping._currency=workspace.currency`; a mapped blank currency is rejected. Supplied optional mapped values are validated rather than replaced. Manual offers preserve their entered fields. IDs are generated; duplicate quote identities are checked by the analyzer.
- `evaluateOffer(item,offer,workspace)` returns `{offer,eligible,reasons:[],warnings:[],packs,units,overage,goodsCost,deliveryCost,total}`; costs decimal strings; reasons block invalid quantities/money/currency/expiry/stock/lead constraint/item identity. Missing stock/lead/expiry are warnings unless needed for a requested constraint. Min pack purchase respected. Availability is total stock packs; cannot buy excessneeded.
- `analyze(workspace)` returns `{items:[{request,offers:[evaluation],selected:evaluation|null,cheapest:evaluation|null}],total,complete,issues:[],warnings:[]}`; total is selected eligible subtotal, complete only every request valid and chosen eligible and nonemptyrequest. Different pack sizes are compared at whole-pack goods cost plus the delivery fee for that offer line. Both conflicting and exact duplicate supplier+quoteId+itemId identities block every involved row.
- `fingerprint(workspace)` returns a deterministic canonical content string. It excludes history, importErrors and revision and includes schemaVersion, workspace ID, title, date, currency, request, offers, selections and notes. It is not a cryptographic hash or signature. Application approval lookup separately requires both the current revision and the fingerprint to match.
- `createReceipt(workspace,nowISO)` throws unless the comparison is complete and the timestamp valid. It creates a new JSON record with kind/schemaVersion/id/workspaceId/title/revision/fingerprint/approvedAt/currency/total/lines (selection+source+reason)/snapshot. A receipt records a local review; it does not authenticate an approver or authorize an order.
- `exportDecisionCsv(workspace)` returns CSV with selected source references/reasons/costs; escape spreadsheet formulas for textcells.
- `validateWorkspace(input)` returns `{valid,errors:[]}`; untrusted portable import strictly checks schema/types/caps, bounded strings, IDsuniqueness, arrays/maps/historylimits. Reject dangerousproto keys; do not let malicious backups execute HTML.

The application clones and validates edits, increments the revision, then saves; historical receipts remain copies of their original inputs. A selection change makes the previous review historical. Domain functions do not mutate their inputs. Unknown stock, lead time and expiry remain explicit; an unmapped delivery-fee column defaults to zero as documented above. Money uses no floating-point arithmetic. Decision CSV text is neutralized against formula interpretation, and imported text is escaped in the UI.

Verification covers arbitrary requests, MOQ, whole-pack rounding, delivery-fee countercases, exact money, duplicate identities, inclusive expiry, unknown availability, lead constraints, currency mismatches, quoted multiline CSV, atomic import rejection, safe CSV export, revision/content identity and hostile backups. The [current test and browser evidence](evidence/TASK-FIRST-UI-QA.md) distinguishes automated harness checks from actual browser observations. These synthetic checks establish behavior within their recorded scope, not customer benefit, adoption or commercial results.
